title: Installation
description: How to install the RealtimeMeshComponent, and the difference between the Core and Pro versions.
---

The current release (v5.4) supports **Unreal Engine 5.5 through 5.8**. Older RMC releases go back as far as UE 5.0 and are still available on GitHub.

There are two ways to get RMC: through Fab (Epic's marketplace), or as source code from GitHub. Both give you the same "Realtime Mesh Component Pro" plugin. GitHub additionally hosts a free **Core** build alongside the paid **Pro** build.

* [Install from Fab](./installation-from-marketplace/) is the quickest route if you just want the plugin in your project.
* [Install from GitHub](./installation-from-github/) is for source access, the free Core version, or following development.
* [Examples](./examples/) explains where the sample content lives once you have the plugin installed.

Once it is installed, head to the [Quickstart](../quickstart/) and build your first mesh.
