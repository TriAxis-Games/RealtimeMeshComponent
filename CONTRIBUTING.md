# Contributing to Realtime Mesh Component

Thank you for your interest in improving the Realtime Mesh Component (RMC)!

## Reporting issues

Please report bugs and feature requests through the issue tracker at
https://github.com/TriAxis-Games/RealtimeMeshComponent/issues. Include your
engine version, plugin version/edition (Core or Pro), platform, and a minimal
reproduction where possible.

## Pull requests

- Keep changes focused: one fix or feature per pull request.
- Match the surrounding code style and conventions of the module you touch.
- Public API compatibility is a hard requirement — breaking changes to
  existing public headers need discussion in an issue first.
- Note in the PR description which engine versions you built/tested against.
